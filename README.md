# Smart Study Planner
A simple study planner built with HTML, CSS, and JavaScript.  

#  Live Demo
 https://edenalemayheu.github.io/Smart-study-planner-/

#  Features
- Add tasks with subject tags  
- Mark tasks as done  
- Delete tasks  
- See total tasks and completed tasks 

# How to Use
1. Type a task in input box.  
2. Choose a subject.  
3. Click "Add" to save the task.  
4. Use "Done" or "Del" to manage tasks.
